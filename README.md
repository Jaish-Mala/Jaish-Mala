# Mars Abodde Properties

A modern real estate property listing website built using HTML, CSS, JavaScript, PHP and MySQL.

## Features

- User Registration & Login
- Property Listing
- Add to Favorites
- Search Properties
- Multiple Property Images
- Responsive Design
- User Dashboard

## Tech Stack

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- XAMPP
- Git
- GitHub

## Project Modules

- Home Page
- User Authentication
- Property Listings
- Favorites
- User Dashboard
- Property Details
- Contact Page
